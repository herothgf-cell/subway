지하철 노선 확장

신림~강남에서 2호선 순환선 전체로, 구간별 특성

1. 목적

  • 캐릭터별 출퇴근 구간(02)과 주말 약속 목적지(04)를 담을 수 있게 노선을 넓힌다.
  • 역이 늘어나는 것 자체보다, 구간마다 타고 내리는 사람이 다르다는 차이를 만드는 것이 핵심이다.

한강을 건너는 구간(당산철교, 잠실철교)은 창밖이 밝아지는 연출 구간으로 쓴다. 역 사이가 길어 체력 소모는 크지만 덜컹거림이 없는 "숨 고르기" 구간으로 설정한다.

4. 순환선 규칙 (3단계)

  • 승강장에서 내선 / 외선을 고른다. 기본은 짧은 방향이다.
  • 돌아가기: 먼 방향을 타면 정거장이 훨씬 많지만 한산한 구간을 지난다. 대신 도착 시각이 늦어져 지각 위험이 생긴다 (04 일정의 도착 시한).
  • J 성격 표현: 플래너에 두 경로의 예상 소요 시간과 혼잡도를 미리 보여 주고 고르게 한다.

5. 역 데이터 구조

{
  id: "sadang", name: "사당",
  transfer: ["4"],          // 환승 노선. 물갈이 등급 계산에 사용 (05 문서)
  grade: "S",               // 환승 등급 S/A/B/없음
  zone: "gwanak",           // 구간 (승객 유형 가중치)
  gap: 1.0,                 // 다음 역까지 구간 길이 배수
  alight: { am: {...}, pm: {...}, weekend: {...} }  // 승객 유형별 하차 가중치
}
  • 현재 코드는 STATIONS 배열과 승객 유형(ARCH)마다 역 이름으로 가중치를 적는 방식이다. 역이 43개가 되면 유형마다 역을 다 적을 수 없으므로, 역이 구간을 갖고 승객 유형이 구간별 가중치를 갖는 구조로 바꾼다.
  • 특정 역에만 해당하는 유형(과잠 → 서울대입구)은 예외 항목으로 덧붙인다.

6. 노선도 UI

  • 통근 중 상단 노선도는 현재처럼 내 구간만 직선으로 보여 준다.
  • 캐릭터 선택과 일정 화면에서는 순환선 전체를 원형으로 보여 주고 집·회사·약속 장소를 핀으로 찍는다.

7. 미결 사항

아래 항목은 구현 전에 Claude Code에서 항목별로 검토 → 선택지와 추천안 제안 → 결정을 거쳐 확정한다. 결정 내용은 plan/v1/DECISIONS.md에 기록하고 이 문서 본문에 반영한다.

  • 지선 포함 여부 → 결정(2026-11-24): 넣지 않는다.
  • 15정거장 구간이 길다 → 결정: 앉은 상태에서 X로 "앉은 채 도착" 건너뛰기. 6배로 감고, 일어서거나 양보 상황이 생기면 멈춘다.
  • 역 이름·환승 정보는 실제 2호선 기준으로 채웠다. 최종 검수 필요 (아래 8장의 표).

8. 1차 구현 내용 (2026-11-24)

  • 순환선 43역을 내선 순서로 넣었다. 통근은 늘 짧은 방향으로 탄다. 내선·외선 "돌아가기"는 04 도착 시한과 함께 뒤에.
  • 승객 하차 가중치: 기존 신림~강남 9역은 원래 값을 그대로 쓴다. 그 밖의 역은 유형별 예외 역 → 구간 가중치 순서로 정한다. "환승 경로를 검색하는 사람"은 환승 등급(S 5 / A 3 / B 1.5)으로 정한다.
  • 환승 등급은 05 표대로. 출발역과 종점에서는 물갈이·쓸려 내림이 없다.
  • 한강 구간(당산–합정, 강변–잠실나루): 주행 시간 1.6배, 덜컹거림 없음(정차 전 제동만). 창밖 연출은 뒤에.
  • 상단 노선도: 10정거장이 넘으면 출발역, 종점, 지금 역 앞뒤 역만 이름을 적는다.
  • 안내방송: 환승 노선과 영어 역명을 43역 모두 넣었다.
