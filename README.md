# 자리사수

서울 지하철 2호선에서 곧 내릴 승객을 예상하고, 사람들 사이를 지나 빈자리에 앉는 1인칭 3D 브라우저 게임입니다.

게임은 [클레이 애니메이션 시안](concepts/index.html#clay)을 바탕으로 만들었습니다. 붐비는 객차 안에서 인형 승객의 옷차림과 소지품, 일어날 때의 손발 움직임을 보고 하차를 예상합니다.

## 실행

저장소를 내려받아 `index.html`을 브라우저로 여세요. 3D 객차는 WebGL 2를 사용합니다. Three.js r180과 라이선스는 `vendor/`에 포함되어 있어 오프라인에서도 실행됩니다. WebGL 2를 사용할 수 없는 브라우저에서는 기존 2D 시점으로 플레이합니다. GitHub Pages에서는 저장소 루트를 배포 대상으로 사용할 수 있습니다.

## 첫 출근

1. 객차를 **마우스로 드래그**하거나 터치 화면에서 밀어 좌우·위아래를 둘러보세요. PC에서 **마우스 고정**을 켜면 버튼을 누르지 않고 시점을 바꿀 수 있고, 화면 가운데로 승객을 겨눠 클릭합니다. **Esc**로 고정을 풀고, 객차에 초점이 있는 상태에서 **Home**으로 처음 방향을 볼 수 있습니다.
2. **출근 시작**을 누르세요. **WASD** 또는 **방향키**로 바라보는 방향을 기준으로 움직여, 앞사람의 어깨에 가려졌던 좌석을 살펴보세요.
3. **승객의 손과 발을 살펴보세요.** 좌석에 마우스를 올리거나 관찰창의 화살표를 누르면 같은 동작을 크게 볼 수 있습니다. 소지품을 만진 뒤 다시 무릎에 내려놓는지, 몸을 앞으로 옮기는지 지켜보세요. 승객을 클릭하거나 숫자 키 **1~6**으로 하차 예상을 정하세요.
4. 통로 바닥을 클릭하거나 키보드로 자리가 빌 곳까지 이동하세요. 가까이에서 **E**, **스페이스**, 또는 빈자리 클릭으로 앉습니다. 경쟁 승객이 먼저 앉으면 다음 정거장에서 다시 기회가 생깁니다.

출근길은 대림에서 신도림과 문래를 거쳐 영등포구청까지 이어집니다. 퇴근길에는 반대 방향을 탑니다. 편도 운행이 끝나면 다음 편도로 넘어가거나 같은 배치를 다시 연습할 수 있습니다. 연습에서는 포인트가 중복 지급되지 않습니다.

포인트로 관찰력과 균형 감각을 올릴 수 있습니다. 진행한 편도와 포인트, 스킬은 브라우저 저장 공간에 기록됩니다. 저장 공간을 사용할 수 없는 경우 현재 창을 열어 둔 동안 유지됩니다.
