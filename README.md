# 계획대로, 2호선

파워 J 직장인이 서울 지하철 2호선 신림↔강남 출퇴근길에서, 누가 곧 내릴지 읽고 인파를 헤쳐 계획한 자리에 앉는 브라우저 게임입니다.

**▶ 플레이: https://herothgf-cell.github.io/subway/**

## 실행
브라우저에서 위 링크로 바로 플레이할 수 있습니다. 로컬에서는 `index.html`을 브라우저로 여세요.

## 화면
어깨 너머 시점의 3D가 기본입니다. 화면을 클릭하면 마우스로 둘러볼 수 있고, V로 객차 전체가 보이는 탑뷰와 전환합니다. 관련 파일은 `index.html`(게임 규칙과 화면 틀), `game3d.js`(3D 그리기), `characters.js`(승객 캐릭터)이며, three.js는 CDN에서 불러옵니다. 이전의 쿼터뷰 2.5D 버전은 저장소 기록에 남아 있습니다.

## 처음 켜면
짧은 인트로(알람 → 플래너 → 승강장 → 문 열림) 뒤 캐릭터를 고르고, 1주차 월요일 출근이 튜토리얼로 이어집니다. 인트로는 클릭이나 아무 키로 넘기고, Esc로 건너뜁니다. 두 번째부터는 승강장 컷 뒤 타이틀 화면(출근하기 / 불러오기)이 나옵니다. 진행은 통근 직전과 주말에 저장되어 불러오기로 이어 할 수 있습니다.

## 목표
출근은 신림에서 강남(회사)까지, 퇴근은 강남에서 신림(집)까지 8정거장입니다. 도착할 때까지 체력을 지키세요. 월요일 출근부터 금요일 퇴근까지 버티면 한 주 개근입니다.

## 조작
| 키 | 동작 |
|---|---|
| WASD | 이동 (내리는 사람 앞에서 A/D는 몸을 90도 돌려 길 터 주기 + 그쪽 막기) |
| 마우스 | 둘러보기 (시야 안 승객의 몸짓만 보임, 좌우 방향키도 가능) |
| 클릭 / F | 보고 있는 승객의 자리 찜하기, 빈자리를 보고 클릭하면 앉기 |
| E | 앉기, 일어서기, 자리 양보 |
| 우클릭(누르고 있기) / Shift / Space | 손잡이 잡기 (급정거 대비, 좌석 앞 손잡이 줄과 출입문 옆 기둥에서만) |
| Tab | 계획표 접기 / 펴기 |
| Q | "잠시만요" (스킬 해금 후) |
| B | 뛰어타기: 출발역에서 다른 문으로 (오신입) |
| X | 앉은 채 도착까지 건너뛰기 |
| T | 백팩 앞으로 메기 (백팩을 챙긴 날) |
| C | 커피 마시기 (텀블러 커피를 챙긴 날, 통근당 1회) |
| V | 3D / 탑뷰 전환 |
| Esc | 일시정지 (가이드) |

시험용: 주소 뒤에 `?debug=1`을 붙이면 통근 중 1 붕괴 스택 +1, 2 체력 -20, 3 민폐 +20. 달력은 기본 2026년이고, `?year=2027`로 연도, `&start=05-04`로 1주차 날짜를 바꿀 수 있다(새 런부터).

기획 내용은 [PLAN.md](PLAN.md)에 있습니다.

추가 기획서(v1, 17건)는 [plan/v1/index.html](plan/v1/index.html)에 있습니다.
