# 계획대로, 2호선

파워 J 직장인이 서울 지하철 2호선 신림↔강남 출퇴근길에서, 누가 곧 내릴지 읽고 인파를 헤쳐 계획한 자리에 앉는 브라우저 게임입니다.

**▶ 플레이: https://herothgf-cell.github.io/subway/**

## 실행
브라우저에서 위 링크로 바로 플레이할 수 있습니다. 로컬에서는 `index.html`을 브라우저로 여세요. 외부 파일이 없는 단일 HTML이라 GitHub Pages에서도 그대로 동작합니다.

## 목표
출근은 신림에서 강남(회사)까지, 퇴근은 강남에서 신림(집)까지 8정거장입니다. 도착할 때까지 체력을 지키세요. 월요일 출근부터 금요일 퇴근까지 버티면 한 주 개근입니다.

## 조작
| 키 | 동작 |
|---|---|
| WASD | 이동 (내리는 사람 앞에서 A/D는 몸을 90도 돌려 길 터 주기 + 그쪽 막기) |
| 마우스 | 시선 돌리기 (시야 안 승객의 몸짓만 보임, 방향키도 가능) |
| 클릭 / F | 보고 있는 승객의 자리 찜하기, 빈자리 클릭은 앉기 |
| E | 앉기, 일어서기, 자리 양보 |
| Shift / Space | 손잡이 잡기 (급정거 대비) |
| Q | "잠시만요" (스킬 해금 후) |
| V | 쿼터뷰 / 탑뷰 전환 |
| Esc | 일시정지 |

기획 내용은 [PLAN.md](PLAN.md)에 있습니다.
