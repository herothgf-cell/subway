# 계획대로, 2호선 — 기획서 (v2)

기존 「자리사수」 프로토타입(저장소 루트)을 참고해 컨셉과 시스템을 다시 잡은 버전입니다.
실행: `v2/index.html`을 브라우저로 열면 됩니다. 외부 파일이 없는 단일 HTML입니다.

## 1. 한 줄 소개
파워 J 직장인이 2호선 신림↔강남 출퇴근길에서, 누가 곧 내릴지 읽고 인파를 헤쳐 **계획한 자리**에 앉는 탑뷰 로그라이트.

## 2. 기존 버전에서 바꾼 것

| 항목 | 기존 | v2 | 이유 |
|---|---|---|---|
| 시점 | 1인칭 3D | 탑뷰 2D | 객차 전체의 빈자리와 동선이 한눈에 보여야 "눈치 + 컨트롤"이 성립. 모바일 이식도 쉬움 |
| 구간 | 3개 역 | 8개 역 (신림~강남) | 역마다 내리는 사람이 달라야 예측이 의미 있음 |
| 주인공 성격 | 설정 없음 | 찜(계획) 시스템 | J 성격을 규칙으로 표현 |
| 실패 조건 | 체력만 | 체력 + 민폐 게이지 | 부대낌과 오해를 별도 위험으로 분리 |
| 진행 | 편도 반복 | 주간 런(월~금 10회 통근) | "게임 종료 → 포인트 → 패시브" 루프를 명확히 |
| 플랫폼 | PC 웹 | PC 웹 유지 | 마우스 + 이동키 조작이 핵심 |

## 3. 코어 루프
1. **승강장**: 4개 문 중 탈 곳을 고른다. 안내판 혼잡도는 대체로 맞지만 오차가 있다.
2. **탐색**: 승객에 마우스를 올려 차림새를 읽는다. (과잠 대학생 → 서울대입구, 등산복 → 사당, 서류 봉투 → 서초·교대, 잠든 승객 → 종점)
3. **계획**: 내릴 것 같은 승객을 클릭해 자리를 찜한다.
4. **이동**: WASD로 사람 사이를 빠져나가 찜한 자리 앞을 선점한다.
5. **착석 경쟁**: 자리가 비면 주변 승객도 노린다. E로 먼저 앉는다.
6. **정산**: 편도마다 포인트, 주가 끝나면(완주 또는 탈락) 포인트로 패시브 스킬을 찍고 새 주를 시작한다.

## 4. 핵심 시스템

### 눈치 (하차 예측)
- 승객 유형마다 자주 내리는 역이 다르다. 출근과 퇴근에서 목적지가 달라진다.
- 내리기 직전에는 몸을 들썩인다. 난이도가 오르면 내리지 않으면서 들썩이는 **페이크**가 섞인다.

### 계획 (J 성격)
- 낌새가 보이기 **전에** 찜한 자리에 앉으면 "계획대로!" +30P, 체력 +6.
- 낌새를 보고 찜했다면 "눈치 착석" +12P.
- 찜한 자리를 남에게 뺏기면 "계획 붕괴"로 체력 -5.

### 컨트롤 (인파)
- 부딪히면 "죄송합니다"와 함께 민폐 게이지 상승, 체력 -3.
- 같은 사람에게 오래 붙어 있으면 민폐 게이지가 계속 오른다. (치한 오해 소재는 이 게이지로 추상화)
- 출발, 정차, 덜컹거림 때 Shift로 손잡이를 잡지 않으면 밀려나 연쇄 충돌이 난다.

### 체력
- 서 있으면 계속 줄고, 혼잡할수록 빨리 준다. 앉으면 회복되고 시간이 빨리 흐른다.
- 남은 체력은 다음 통근으로 이어진다. (회사 +18, 수면 +42)
- 0이 되면 그 주는 종료.

### 양심
- 임산부 배려석은 비어 있어도 앉으면 민폐 게이지가 계속 오른다.
- 앉아 있을 때 어르신이 앞에 서면 E로 양보할 수 있다. +25P, 민폐 -30. 버티면 민폐가 오른다.

## 5. 패시브 스킬

| 스킬 | 단계 | 효과 |
|---|---|---|
| 관찰력 | 3 | 자주 내리는 역 표시 → 페이크 간파 → 남은 정거장 수 표시. 단계마다 낌새가 더 일찍 보임 |
| 균형 감각 | 3 | 급정거에 밀리는 거리 감소 |
| 출근 체력 | 3 | 서 있을 때 체력 소모 감소 |
| 플랜 B | 2 | 찜 슬롯 증가 (최대 3) |
| "잠시만요" | 2 | Q로 주변 승객이 길을 터 줌 |
| 빠른 엉덩이 | 2 | 착석 거리 증가, 경쟁자 반응 지연 |
| 철면피 | 2 | 민폐 게이지 상승 감소 |

## 6. 난이도 곡선
- 요일이 지날수록, 퇴근길일수록 서 있는 승객이 늘고 경쟁자 반응이 빨라지며 페이크가 늘어난다.
- 금요일 퇴근까지 버티면 개근 보너스 +80P 후 다음 주차(더 혼잡)로 이어진다.
- 날마다 변수: 비 오는 날(더 비좁음), 열차 지연(혼잡), 한산한 날.

## 7. 디자인 컨셉
- **노선도 그래픽**: 2호선 초록(#00A84D), 안전선 노랑, 배려석 분홍만 강조색으로 쓰는 평면 다이어그램 스타일.
- HUD는 역명판과 전광판을 본뜬 형태. 주인공은 초록 셔츠와 사원증 줄로 구분.
